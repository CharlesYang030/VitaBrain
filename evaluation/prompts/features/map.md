在线视觉 BEV 已开启。它从本轮 RGB 和公开动作里程计估计地面与边界，没有游戏真值。MAP_IMAGE 中浅色是视觉估计地面、深色是未知，橙色是估计阻挡边界；青色细线仅为实际轨迹。局部图帮助判断通道，全局图帮助记住入口与连接。颜色表示估计，不保证机器人身体和手持物可以通过。不要把未知区域当成墙或已探索，也不要把图中的编号当成对象操作 handle。
spatial_memory 提供地图坐标、当前位姿、已观察的地点与入口、来源和不确定性。换层后是新的局部坐标，未确认对齐不能直接相减。同一楼层不同局部图可能重叠，不能当成已知全局平面图。
有新地点或重要入口时增加 place_update={"id":"已有地点编号或new","label":"当前图像中的地点特征","confidence":0.6,"source_observation_id":"当前编号"}。不确定是否重访时用 new 并降低置信度，不能凭相似白墙认成同一房间。
可增加 visual_landmarks=[{"kind":"portal|landmark","label":"简短视觉特征","x":0.5,"y":0.8,"confidence":0.7,"source_observation_id":"当前编号"}]。x,y 指向当前 FPV 中入口或物体底部邻近的可见地面接近点，不是世界坐标；看不见接近地面就不填，不估造精确距离。是否穿过入口与是否完成搜索仍需依据之后的实际观察判断。
开启地图时，每次 JSON 都包含 place_update 和 visual_landmarks。初次到达一个可辨识地点时记录其特征；没有新信息或不能识别时分别填 null 和 []，不要省略字段，也不要为了填字段编造地标。
