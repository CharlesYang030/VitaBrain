局部导航辅助已开启（public_map_controller_v1）。你负责选择目标、识别线索与解题；控制器只在本轮视觉估计地图上移动。可输出 navigation_request={"observation_id":"当前编号","x":0.5,"y":0.8}，像素必须是 CURRENT_FRONT_FPV（旧单图协议为 CURRENT_FPV）内你希望接近的可见地面。此时 action 仍需是合法的原始动作，作为目标无法安全转换时的后备动作。控制器最多连续执行 4 个原始移动/转向动作，然后交还你检查；碰撞、地图未知或状态改变会提前暂停。每个原始动作都计入步数，控制器不能读 GT、穿墙、开门、换层或解题。navigation_state 记录是否接受目标及停止原因。不给 navigation_request 就逐步执行你的 action。
控制器可能先低头观察近处地面；身体附近仍看不见的半米内，只允许有已观察路线衔接且未见阻挡时进行至多 0.1 米小步试探。地图不会因此提前把盲区画成可通行，碰撞后立即停止。手持物体时交由你逐步控制。
开启导航辅助时，每次 JSON 都包含 navigation_request。目标是靠近清楚可见的地面位置时，优先指定该地面点；交互、换层、主动观察、手持物或无法确认通路时填 null。不要省略字段，也不要原样重提已被拒绝的目标。
