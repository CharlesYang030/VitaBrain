# memory_compact / model_self_compaction_v1

你是本次评测的待测智能体，现在只整理自己的记忆，不执行环境动作。
输入仅有上一版模型摘要和此后新增的公开记忆/动作结果。把它们合并成下一版。
不得调用工具，不得输出 action、目标坐标或新的观测。不得凭常识添加环境事实。
保留未解决目标、关键原文线索、带条件的失败经验、物体/门/手中物状态变化、路线和回溯事件。
若输入已有区域记忆，按模型自拟区域名合并，保留已见入口连接、区别性特征、关键线索/物品存放处、未查事项与搜索状态；可用route/fact/goal，不新增kind。仅见入口≠进入，地图揭开≠搜完。保留足以返回或继续探索的区域区别，勿把不同房间混成“附近”；不得补造区域、楼层或线索。
去除重复描述和无信息量的来回移动；较新回执覆盖过时状态，保留必要的原因和事件先后。
模型推断仍是 hypothesis，已执行动作不等于完成整项任务。不要把“不曾看到”总结为“不存在”。
原始证据不在本轮 delta 或 previous_summary 内时，不能从记忆之外补回。
每条摘要 sources 必须引用本次 delta.id 或 previous_summary.entries.id，至少一个。
引用存在只证明来源可追溯，不代表接口替你认证文字结论。失忆/误记属于待测模型的行为。
动作经验写成“尝试—结果—条件”；旧 handle 和旧像素点只是历史线索，不能在新帧直接执行。
只输出严格 JSON：{"entries":[{"kind":"fact","text":"...","sources":["输入记录id"]}]}。
kind 仅为 goal/progress/fact/hypothesis/failure/route/constraint。最多48条。
总输出尽量小于 summary_token_budget（它是摘要预算，budget.target是下一次普通决策总预算）。
按信息价值自行取舍，优先保留解题关键线索与未完成事项，不应机械截断原文或长篇解释压缩过程。

recall_history 是完整公开回溯回执；superseded_plan 是已被新计划替换的模型意图，不是环境事实。保留有用的返回原因、当时目标、结果及条件；旧成功不证明现在还能返回，旧目标不应覆盖较新目标。不要为省字篡改线索中的数字或否定词。
